🎯 QR Queue System - Quick Test Guide

Step 1: Open Queue Monitor Dashboard

Click the button below to open the real-time monitoring dashboard:

📊 Open Queue Monitor

Or manually open: http://localhost:5000/qr-queue-monitor.html

Step 2: Test Adding Requests

On the dashboard, you'll see 3 test buttons:

  • ➕ Thêm Request (Free) - Add 1 free user request
  • ⭐ Thêm Request (Paid) - Add 1 paid user request (higher priority)
  • 🔥 Thêm 10 Requests - Add 10 requests at once (simulate load)

Try this: Click "🔥 Thêm 10 Requests" and watch what happens!

Step 3: Observe the Queue in Action

You should see:

  • 📊 Stats Cards updating in real-time
  • ⚡ Active Requests section showing up to 10 requests being processed
  • ⏳ Queued Requests section showing requests waiting in line
  • 🔄 Dashboard auto-refreshes every 2 seconds

Test that paid users get priority:

Step 6: Check API Endpoints

You can also test via API:

✅ What You Should See

When adding 10 requests:

  • First 10 requests → Processed immediately (Active Requests section)
  • After ~30 seconds → Requests complete and disappear
  • "Total Processed" counter increases

When adding 15+ requests:

  • First 10 → Active (processing)
  • Remaining 5+ → Queued (waiting)
  • Queue shows position (#1, #2, #3...)
  • As active requests complete, queued ones move to active

When adding 100+ requests:

  • First 10 → Active
  • Next 100 → Queued
  • Remaining → Rejected (queue full)
  • "Total Rejected" counter increases

🐛 Troubleshooting

If dashboard doesn't load:

  • Check server is running: dotnet run
  • Try: http://localhost:5000/qr-queue-monitor.html

If buttons don't work:

  • Open browser console (F12) and check for errors
  • Verify API is working: Test API
